# R5.04-groupe-1
Projet de Ressource 5.04 de l'agence A

## Contexte

La Ressource 5.04 est une ressource à compléter en groupe hétérogène composé de membres des différents parcours de MMI (DEV,CREA,STRAT).
L'objectif établit par les professeurs au début de cette ressource est de produire un Webdoc et un podcasts sur le thème (choisi lui aussi par les professeurs) de la découverte de MMI et des métiers après celui-ci.

Le groupe est composé de 12 membres (avec une répartition par parcours choisi par les professeurs) dont voici la liste :
- Nathan Cairon,
- Oscar Claire,
- Maxime Croissant,
- Arséne Devaud,
- Tina Droniou,
- Emilie Eono,
- Hugo Joubat,
- Willy Lecenne,
- Matthieu Meslé,
- Owen Serreau,
- Klervi Texier,
- Victor Verhaeghe.

La ressource est décrite comme donnant "Une grande liberté d’action".


## Concept

Ce site internet est un Webdoc présentant les différentes interviews et podcasts produits pour ce devoir.
Nous réfléchissont actuellement à inclure un back pour pouvoir contrôler facilement le contenu affiché sur le webdoc.
